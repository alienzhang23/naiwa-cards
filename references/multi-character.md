# 多角色选角与一致性

## 可用角色

| 角色 | 档案 | 参考 | 关键区分 |
| --- | --- | --- | --- |
| 当前主角 | `config/active-ip.md` 指向的档案 | 配置指向的参考图 | 以当前配置为准；当前奶蛙不是默认团子奶娃 |
| 奶鼠 | `ips/naishu.md` | `assets/character/nai-family/ref-naishu-naidan-source.jpg` 左侧 | 超大圆耳、鼠尾、黄色短四肢，无奶蛙腹斑 |
| 奶蛋 | `ips/naidan.md` | 同一截图右侧 | 完整蛋形，无可见四肢/耳尾，无腹斑 |

所有相对路径相对于 skill 根目录。共享截图只需作为一份图像参考传入；提示词明确左侧奶鼠、右侧奶蛋，不能把 A/B、名字标签、手机界面或背景画入新图。截图不是干净定妆图，需用档案同时锁定身份；出现混淆时可按需生成独立定妆图并检查后存档，不自动覆盖原图。

## 选角

- 默认当前激活 IP 单独出镜。对比、状态变化、连续分镜可让同一 IP 多次出现，这表示同一个身份的不同实例/阶段，不自动引入新角色。
- 当内容需要交接、协作、问答、帮助、对立关系时，可从角色库中选主角加奶鼠或奶蛋；通常 2 个不同角色足够，确有必要或用户指定时可用 3 个。不为“多角色”而凑齐全员。
- 用户指定角色或组合时优先执行；未指定时以当前 IP 为主角，配角按动作适配选择。配角入库不更改 `config/active-ip.md`。
- 职业和任务只是本次画面的分工，不永久绑定角色；在同一套内保持分工一致，除非故事明确发生变化。

## 生成前的角色表

为每个出场角色写明：名字/slug、参考文件和图中位置、身份锁定句、本次职责、具体动作、场景位置、配色及辨识点。涉及多角色时读取各自档案并传入全部所需参考；共享文件去重。将角色表和各自锁定句填入生图模板，不只写“画三只黄色角色”。

每个角色都应承担因果上必要的动作或状态，不能只作围观装饰。奶蛋无肢体：例如它用身体压住会回卷的任务纸，奶鼠才能将纸送进槽口；不要安排奶蛋拿笔、握手、举牌或拧钥匙。不要为了必须抓握而改变角色解剖。

## 配色和 QA

单角色时仅该角色使用招牌色；多角色时，每个已选角色分别保留各自档案配色，道具仍为不填色黑线。不要把“只有主角有颜色”执行成其他角色全黑，也不要让黄色扩散到机器、桌子或本子。

检查实际角色数、身份与动作对应、参考是否串用：奶鼠耳尾不能长在奶蛋上，奶蛙腹斑和棕色手脚不能长在奶鼠上，奶蛋不能长出四肢。同一 IP 的多实例需外形一致；不同 IP 应通过轮廓区分，不靠角色名字标签补救混淆。
