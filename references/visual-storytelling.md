# 场景隐喻与构图

## 从内容生长出画面

先写一句准确的核心判断，再问“这个变化在物理世界里像什么？”

1. **选动作**：接不住、漏掉、分拣、变重、折叠、拆包、回流、修补、卡住、释放。动作必须对应文章的关系，不能只画主题相关物件。
2. **选物件**：从日常低科技物件中选 1–2 个，如抽屉、秤、衣架、门、夹子、纸箱、手摇装置。物件可以荒诞组合，但输入、操作、结果应讲得通。
3. **安排角色**：让当前 IP 推、接、称、拆、缝、拧、搬、守或操作装置。保持身体造型，把荒诞感放在任务和装置中，不靠身体变形或卖萌。
4. **删文字**：先靠场景表达，再补 3–5 处短标注。删掉标题后，读者也应能感到主要关系。

反例：标题说“工具太多”，角色在旁边指着四条建议，画面没有表现过载。
正向构思示例：角色忙着接不同工具递来的把手，真正要完成的任务仍放在脚边。这个示例只说明概念转译方法，不是默认构图。

## 按关系选择结构

| 内容关系 | 场景组织 | 避免 |
| --- | --- | --- |
| 输入、处理、输出 | 一个有明确操作与结果的装置 | 多个方框串箭头 |
| 前后差异 | 相同任务的两种操作和结果 | 只换角色表情 |
| 状态变化 | 2–4 个动作连续的小场景 | 每格重复大段正文 |
| 筛选、判断、取舍 | 让角色实际称重、挑选或开关 | 只有概念标签 |
| 方法层次 | 搭建、收纳或支撑关系 | 正式金字塔和层层盒子 |
| 清单、具体步骤 | 少量编号与角色演示 | 强行给事实清单套牵强隐喻 |

3:4 用上下或斜向空间组织动作，保留角色与装置的完整关系；16:9 用横向因果、两侧对照或展开的单场景。改变比例时重新安排标题和标注，不能仅改变画布大小。

## 原创与审美

每张重新选择动作和物件，同套避免反复用同一种机器或同一套版式。参考图锁 IP，案例图校准线条、留白、色彩，不承担构图模板职责。

不要默认复用小黑仓库的压机出钥匙、证据搭桥、切素材鱼、角色变漏斗等案例。若想到的画面与案例高度相似，保留观点，替换物件和操作方式。用户明确要求复刻某图时按其要求执行。

画面可以不合理，概念关系必须合理。幽默来自“角色很认真地完成奇怪任务”，而不是闪亮眼睛、夸张表情或随机道具堆积。
